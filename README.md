# make-knowledge-cards

## 介绍

把一篇文章变成 5–8 张真正值得复习的知识卡片。

这是一个纯指令型 Agent Skill，不需要脚本或外部数据源。它可以读取用户粘贴的文章，或本地 `.md` / `.txt` 文件，提炼出重要、互不重复、可追溯到原文的知识点。每张卡片只讲一个知识点，包含标题、核心知识、简明解释，以及原文例子或自测问题。

信息不足时，它会输出更少的卡片并说明原因；不会为了凑满 5 张而拆分、重复或编造内容。

## 特点

- **重要优先**：保留中心论点、机制、关键区别、步骤与限制，删除宣传、闲聊和无关细节。
- **一卡一点**：一张卡片只讲一个知识点，不把同一个观点的“是什么、为什么、怎么做”拆成三张。
- **合并重复**：同一主张的重复表述会合并，不因原文啰嗦而增加卡片数。
- **忠于原文**：不加入外部背景，不把观点写成事实，不改写数字、限定词或归因。
- **数量克制**：通常 5–8 张；原文支撑不足时更少，绝不超过 8 张。
- **纯 Markdown**：结果直接输出在对话中；只有明确要求时才保存为 `.md` 文件。

## 目录结构

```text
.
├── LICENSE
├── README.md
└── skills/
    └── make-knowledge-cards/
        ├── SKILL.md
        └── agents/
            └── openai.yaml
```

Skill 本身是 `SKILL.md` 和 `agents/openai.yaml` 两个文件，没有脚本、模板或第三方依赖。

## 安装与使用

将整个 `skills/make-knowledge-cards/` 目录放入你的 Agent Skills 宿主所扫描的 skills 目录，确保 `SKILL.md` 位于该目录根部。`agents/openai.yaml` 提供 OpenAI/Codex 的界面元数据；其他宿主可以忽略它。

在支持 `$skill-name` 语法的宿主中，可以这样调用：

```text
使用 $make-knowledge-cards 把下面这篇文章整理成知识卡片：

<粘贴文章正文>
```

也可以直接指定本地文件：

```text
使用 $make-knowledge-cards 读取 notes/example.md，生成知识卡片。
```

如果宿主不支持 `$` 语法，直接说“请按 make-knowledge-cards 的规则处理这篇文章”即可。

## 输入输出示例

### 输入

```markdown
海风是白天从海洋吹向陆地的风。白天陆地升温比海洋快，近地面的空气受热上升，气压降低；海面上的空气较冷、气压较高，于是空气从海洋流向陆地。夜间陆地降温更快，气压关系反转，风从陆地吹向海洋，称为陆风。
```

### 输出

```markdown
## 知识卡片：海陆风

> 共 2 张卡片。原文可独立成卡的重点有限，未补足数量。

### 1. 白天海风由海陆气压差推动

- **核心知识**：白天陆地升温快于海洋，近地面空气从海洋流向陆地，形成海风。
- **简明解释**：陆地受热更快，近地面空气上升、气压降低；海面空气较冷、气压较高，空气因此从高压一侧流向低压一侧。
- **例子或自测问题**：自测：白天海风的风向是什么？（从海洋吹向陆地。）

### 2. 夜间风向反转成陆风

- **核心知识**：夜间陆地降温更快，近地面风从陆地吹向海洋，称为陆风。
- **简明解释**：海陆温差方向反转，气压差也随之反转，于是近地面风向与白天的海风相反。
- **例子或自测问题**：自测：陆风主要出现在白天还是夜间？（夜间。）
```

这个例子故意使用了一篇很短的原文：它只支持两个独立知识点，所以只输出两张卡片，而不是为了达到 5 张而重复或拆分内容。正常长度的文章通常会得到 5–8 张。

## 暂不支持

- 网页抓取、URL 总结
- PDF、EPUB、Word、图片、音频和视频
- Anki、CSV 或其他记忆软件格式导出
- 图形界面或独立应用

如果输入是这些格式，请先把正文粘贴为纯文本，或提供 `.md` / `.txt` 文件。

## 验证

Skill 已在科普说明文、操作指南、观点评论和低信息量产品公告四类文本上测试，并通过官方 `skill-creator` 的 `quick_validate.py` 校验。
