# make-knowledge-cards

把一篇文章转换成 5–8 张可以主动复习的知识卡片。

## 1. 项目解决什么问题

读长文时，常见结果是读完就忘；普通摘要只要求“看懂”，不要求回忆；手工做卡片又很耗时。使用通用 AI 总结时，还容易出现把次要信息当重点、重复同一句话，甚至补出原文没有的内容。

本项目把这些步骤收敛成一个可重复的流程：从一篇原文中挑出少量重要、互不重复、可追溯到原文的知识点，做成适合复习和自测的卡片。它适合处理文章、教程、观点评论、项目文档和其他说明性文本。

它保证不加入原文没有的信息，但**不核实原文本身是否真实或过时**；原文中的观点、数据和结论仍需要读者自行判断。

## 2. 主要功能

- **重要优先**：保留中心论点、机制、关键区别、步骤与限制，删除宣传、闲聊、重复段落和无关细节。
- **一卡一点**：一张卡片只讲一个知识点，不把同一个观点的“是什么、为什么、怎么做”拆成多张卡片。
- **合并重复**：同一主张的重复表述会合并，不因原文啰嗦而增加卡片数。
- **固定卡片结构**：每张卡片都有标题、核心知识、简明解释，以及原文例子或自测问题。
- **忠于原文**：不引入外部背景，不把观点写成事实，不改写数字、限定词和归因；观点性内容会标明作者立场。
- **数量克制**：通常生成 5–8 张；原文支撑不足时输出更少并说明原因，绝不超过 8 张，也不为凑数而拆分或编造。
- **纯文本输出**：默认在对话中返回 Markdown，不依赖脚本、第三方服务或密钥；只有明确要求时才保存为 `.md` 文件。
- **中英文内容**：支持中文和英文原文，可在请求中指定输出语言。

## 3. 安装方法

### 环境要求

需要一个支持 Agent Skills、能够读取 `SKILL.md` 的宿主。无需安装 Python、Node.js 或其他运行时，也没有构建步骤。

### 通用安装

1. 将整个 `skills/make-knowledge-cards/` 目录复制到宿主扫描的技能根目录。
2. 确认目标目录中直接存在 `SKILL.md`，即路径形如：
   ```text
   <skills-root>/make-knowledge-cards/SKILL.md
   ```
3. `agents/openai.yaml` 提供 OpenAI/Codex 的界面元数据；其他宿主可以忽略它。

### 在 DSH 中安装

DSH 默认只扫描项目级 `.dsh/skills/`、`.agents/skills/`，或用户级的对应目录，不会直接扫描本仓库的 `skills/`。如果使用 DSH，请将技能目录复制或链接到上述根目录之一，例如：

```text
<project>/.agents/skills/make-knowledge-cards/SKILL.md
```

## 4. 使用方法

在支持 `$skill-name` 语法的宿主中，可以直接粘贴文章：

```text
使用 $make-knowledge-cards 把下面这篇文章整理成知识卡片：

<粘贴文章正文>
```

也可以指定本地 Markdown 或 TXT 文件：

```text
使用 $make-knowledge-cards 读取 notes/example.md，生成知识卡片。
```

如果宿主不支持 `$` 语法，可以直接说：

```text
请按 make-knowledge-cards 的规则处理这篇文章。
```

默认一次处理一个来源；多篇文章会先确认是合并还是分别处理，也可以明确要求分别生成多组卡片。默认输出在对话中，不修改输入文件；只有明确要求“保存为文件”时才会写出 Markdown。

## 5. 输入输出示例

### 输入

```markdown
海风是白天从海洋吹向陆地的风。白天陆地升温比海洋快，近地面的空气受热上升，气压降低；海面上的空气较冷、气压较高，于是空气从海洋流向陆地。夜间陆地降温更快，气压关系反转，风从陆地吹向海洋，称为陆风。
```

### 输出

```markdown
## 知识卡片：海陆风

> 共 2 张卡片。原文可独立成卡的重点有限，未补足数量。

### 1. 白天海风由海陆气压差推动

- **核心知识**：白天陆地升温快于海洋，近地面空气从海洋流向陆地，形成海风。
- **简明解释**：陆地受热更快，近地面空气上升、气压降低；海面空气较冷、气压较高，空气因此从高压一侧流向低压一侧。
- **例子或自测问题**：自测：白天海风的风向是什么？（从海洋吹向陆地。）

### 2. 夜间风向反转成陆风

- **核心知识**：夜间陆地降温更快，近地面风从陆地吹向海洋，称为陆风。
- **简明解释**：海陆温差方向反转，气压差也随之反转，于是近地面风向与白天的海风相反。
- **例子或自测问题**：自测：陆风主要出现在白天还是夜间？（夜间。）
```

这个例子故意使用了一篇很短的原文：它只支持两个独立知识点，所以只输出两张卡片，而不是为了达到 5 张而重复或拆分内容。正常长度的文章通常会得到 5–8 张。

## 项目结构

```text
.
├── LICENSE
├── README.md
└── skills/
    └── make-knowledge-cards/
        ├── SKILL.md
        └── agents/
            └── openai.yaml
```

Skill 本身由 `SKILL.md` 和 `agents/openai.yaml` 组成，不包含脚本、模板或第三方依赖。

## 暂不支持

- 网页抓取、URL 总结
- PDF、EPUB、Word、图片、音频和视频
- Anki、CSV 或其他记忆软件格式导出
- 图形界面或独立应用

如果输入是这些格式，请先把正文粘贴为纯文本，或提供 `.md` / `.txt` 文件。

## 验证

Skill 已在科普说明文、操作指南、观点评论和低信息量产品公告四类文本上测试，并通过官方 `skill-creator` 的 `quick_validate.py` 校验。
